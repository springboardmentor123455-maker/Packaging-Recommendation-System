
# EcoPackAI – AI-Powered Sustainable Packaging Recommendation System

## Description
EcoPackAI is an AI-driven system that recommends sustainable packaging materials using machine learning models and structured datasets.

## Tech Stack
- Python, Flask
- Machine Learning (Random Forest, Gradient Boosting)
- React (Vite)
- CSV-based Data Storage

## How to Run

### Backend
```bash
cd backend
pip install -r requirements.txt
python app.py
